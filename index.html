ETA factory XP Need By

BI Shortage→ROP Demand Converter→Material → FFFC→Planned Order by FFFC→BUn + Qty Convert PO→ETD Allocation by FFFC→Excel: ETA Propose + MRP Table

Step 0 — ROP / Safety Stock Demand Converter: before any FFFC aggregation, each LD Part first checks ROP. If ROP > 0, the existing ROP conversion is unchanged: the first demand bucket receives the ROP-covered quantity; when total horizon demand is below ROP, the first bucket is raised to max(ROP, total demand). Covered weeks become 0; the cutoff week keeps only the amount above ROP; all weeks after cutoff remain exactly as the source. If ROP = 0 and Safety Stock > 0, Safety Stock is added once to the first 01 Demand bucket and no demand/forecast bucket is consumed or rearranged. Example: Demand 1,024 + Safety Stock 4,461 = 5,485. 02 Supply / source 03 Acc Variance are untouched at conversion stage; the exported MRP Acc Variance is recalculated by the existing downstream logic.

Matching key = FFFC from Master List Group No. for both BI LD Part and PO Material. After ROP conversion, the existing logic is unchanged: Stock-0007 and converted demand are combined by FFFC, then PO Backlog is sorted ascending by FFFC → Availability date → PO date → Backlog Qty. Blank dates are placed last. If all four keys are equal, the original PO row order is preserved. Allocation quantity = Qty Convert PO (Order Unit → FFFC BUn). ETA factory XP Need By = the BI timeline bucket immediately before the shortage / Planned Order bucket (example: shortage at 09-Nov-2026 → Need By 02-Nov-2026). If the shortage is already in the first BI bucket, that first bucket is kept. ETA Propose = Need By − lead time. If Qty Convert PO cannot be calculated from units, it automatically uses Backlog Qty. ETA Status compares ETA factory XP Need By with Availability date: earlier = Pull In, later = Push Out, equal = No Change, blank Need By = Excess Supply. When ETA factory XP Need By is blank, ETA Propose is also blank. Gap ETA factory XP Need By &Availability date (Day) = Availability date − ETA factory XP Need By; if Need By is blank, the result is Excess Supply.
